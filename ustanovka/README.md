# Установка «Этикеток»

1. Скачайте [Etiketki-setup.exe](https://github.com/mishamatveyjchuk-alt/etiketki-updates/raw/main/ustanovka/Etiketki-setup.exe).
2. Запустите. Если Windows покажет «Windows защитила ваш компьютер» — «Подробнее» → «Выполнить в любом случае».
3. «Далее» → «Установить» → «Готово». Права администратора не нужны, ярлык появится на рабочем столе.
